পুনর্মিলনী ও এ ধরনের অনুষ্ঠানে একে একে নিজের পরিচয় দেওয়ার জন্য এক-পৃষ্ঠার টাইমার। শুধু ব্রাউজারে `index.html` খুলুন — ইনস্টল, সার্ভার বা ইন্টারনেট লাগে না।

## ব্যবহারের নিয়ম

1. ব্রাউজারে (Safari / Chrome) `index.html` খুলুন।
2. সেটআপ স্ক্রিনে: CSV লোড করুন (`sample/participants.csv` দেখুন, অথবা “নমুনা লোড করুন”), প্রত্যেকের উপস্থিতি বদলান, যেকোনো ফিল্ড দিয়ে সাজান, শিরোনাম / প্রতি বক্তার সময় / সম্বোধন / ভাষা ঠিক করুন, এবং শব্দ পরীক্ষা করুন।
3. “টাইমারে যান” চাপুন (এতে শব্দও চালু হয়)।
4. টাইমার চালান:

| কাজ | ফল |
|---|---|
| `Space` / শুরু বোতাম | পরের বক্তাকে শুরু করুন (করতালিসহ) |
| ডানদিকের তালিকায় নামে ক্লিক | সেই ব্যক্তিকে শুরু করুন; তাঁর আগের জনেরা “বাদ পড়েছেন”-এ যান |
| “বাদ পড়েছেন” তালিকায় নামে ক্লিক | সেই ব্যক্তিকে শুরু করুন |
| “বাদ পড়েছেন” তালিকায় “উপস্থিত” টিক তুলে দিন | নিশ্চিত করার পর অনুপস্থিত ধরে তালিকা থেকে সরানো হয় (টাইমার চলতে থাকে) |

১০ সেকেন্ড বাকি: প্রতি সেকেন্ডে টিক · ৩ সেকেন্ড বাকি: দ্রুত বিপ · ০ হলে: বিস্ফোরণের শব্দ ও “সময় শেষ” লেবেল। উপরে ডানে মোট অতিবাহিত সময় এবং ডানদিকের কলামে পরের ১০ জন দেখা যায়।

## CSV ফরম্যাট

প্রথম সারি হেডার। UTF-8 ও Shift_JIS নিজে থেকেই শনাক্ত হয়। নাম ও সম্বোধনের কলাম হেডার (যেমন `নাম`, `সম্বোধন`) দেখে নিজে থেকে বাছা হয় এবং সেটিংসে বদলানো যায়। সম্বোধনের ঘর খালি থাকলে ডিফল্ট সম্বোধন ব্যবহৃত হয়।

```csv
name,honorific,group,year
Alex Morgan,,A,2001
Sam Rivera,Dr.,B,2001
```

## ভাষা

১৬টি ভাষা: সেটআপ স্ক্রিনের “ভাষা” থেকে বদলান (প্রথমে ব্রাউজারের ভাষা ব্যবহৃত হয়, আপনার পছন্দ সংরক্ষিত থাকে)। ইন্টারফেসের লেখা, শিরোনামের ডিফল্ট, ডিফল্ট সম্বোধন, নমুনা ডেটা এবং সম্বোধনের অবস্থান (নামের আগে/পরে) ভাষা অনুযায়ী বদলায়; আরবিতে ডান-থেকে-বাঁ লেআউট হয়। অনুবাদগুলো মাতৃভাষীরা যাচাই করেননি — ঠিক করতে `index.html`-এর `I18N` সম্পাদনা করুন। নতুন ভাষা যোগ করতে `LANGS`, `I18N` ও `SAMPLE_NAMES`-এ একটি করে এন্ট্রি যোগ করুন।

## মোবাইল

ফোনের পোর্ট্রেট ও ল্যান্ডস্কেপ উভয় লেআউট আছে। iPhone-এ সাইলেন্ট সুইচ চালু থাকলে শব্দ হয় না। ফাইলটি “Files” অ্যাপ থেকে খোলাই সবচেয়ে নির্ভরযোগ্য; GitHub Pages-এ প্রকাশ করলে শুধু URL খুললেই চলে।

## কাঠামো

```
.
├── index.html            # app (HTML / CSS / JavaScript in one file)
├── sample/
│   └── participants.csv  # sample list
├── README.md             # + README.<lang>.md (16 languages)
└── LICENSE               # MIT
```

`index.html`-এ সবকিছু আছে: ভাষার অভিধান, CSV পার্সার, সেটআপ স্ক্রিন, Web Audio দিয়ে শব্দ তৈরি (অডিও ফাইল লাগে না), টাইমারের যুক্তি (টাইমস্ট্যাম্প-ভিত্তিক, তাই সময় সরে যায় না) এবং টাইমার স্ক্রিন। সেটিংস ও অগ্রগতি `localStorage`-এ নিজে থেকে সংরক্ষিত হয়।
