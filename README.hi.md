पुनर्मिलन जैसे आयोजनों में लोगों से एक-एक करके अपना परिचय दिलवाने के लिए एक-पृष्ठ का टाइमर। बस `index.html` को ब्राउज़र में खोलें — इंस्टॉल, सर्वर या इंटरनेट की ज़रूरत नहीं।

## उपयोग कैसे करें

1. `index.html` को ब्राउज़र (Safari / Chrome) में खोलें।
2. सेटअप स्क्रीन पर: CSV लोड करें (`sample/participants.csv` देखें, या “नमूना लोड करें” दबाएँ), हर व्यक्ति की उपस्थिति बदलें, किसी भी फ़ील्ड से क्रमबद्ध करें, शीर्षक / प्रति वक्ता समय / सम्मान-सूचक / भाषा तय करें, और ध्वनि जाँचें।
3. “टाइमर पर जाएँ” दबाएँ (इससे ध्वनि भी चालू होती है)।
4. टाइमर चलाएँ:

| क्रिया | असर |
|---|---|
| `Space` / शुरू बटन | अगले वक्ता को शुरू करें (तालियों के साथ) |
| दाईं सूची में किसी का नाम क्लिक करें | उस व्यक्ति को शुरू करें; उनसे पहले वाले “छोड़े गए” में चले जाते हैं |
| “छोड़े गए” सूची में नाम क्लिक करें | उस व्यक्ति को शुरू करें |
| “छोड़े गए” सूची में “उपस्थित” का निशान हटाएँ | पुष्टि के बाद अनुपस्थित मानकर सूची से हटा दें (टाइमर चलता रहता है) |

10 सेकंड बचने पर: हर सेकंड टिक · 3 सेकंड बचने पर: तेज़ बीप · 0 पर: धमाके की आवाज़ और “समय समाप्त” लेबल। ऊपर दाईं ओर कुल बीता समय और दाईं पट्टी में अगले 10 वक्ता दिखते हैं।

## CSV प्रारूप

पहली पंक्ति शीर्षक पंक्ति होती है। UTF-8 और Shift_JIS अपने-आप पहचाने जाते हैं। नाम और सम्मान-सूचक कॉलम शीर्षक (जैसे `नाम`, `सम्मान-सूचक`) से अपने-आप चुने जाते हैं और सेटिंग्स में बदले जा सकते हैं। सम्मान-सूचक का सेल खाली हो तो डिफ़ॉल्ट सम्मान-सूचक इस्तेमाल होता है।

```csv
name,honorific,group,year
Alex Morgan,,A,2001
Sam Rivera,Dr.,B,2001
```

## भाषाएँ

16 भाषाएँ: सेटअप स्क्रीन पर “भाषा” से बदलें (पहली बार ब्राउज़र की भाषा ली जाती है, चुनी हुई भाषा सहेजी जाती है)। इंटरफ़ेस का पाठ, शीर्षक का डिफ़ॉल्ट, डिफ़ॉल्ट सम्मान-सूचक, नमूना डेटा और सम्मान-सूचक की स्थिति (नाम से पहले/बाद) भाषा के अनुसार बदलते हैं; अरबी में दाएँ-से-बाएँ लेआउट होता है। अनुवादों की मूल भाषियों से जाँच नहीं हुई है — सुधार के लिए `index.html` में `I18N` संपादित करें। नई भाषा जोड़ने के लिए `LANGS`, `I18N` और `SAMPLE_NAMES` में एक-एक प्रविष्टि जोड़ें।

## मोबाइल

फ़ोन के पोर्ट्रेट और लैंडस्केप दोनों के लिए लेआउट। iPhone में साइलेंट स्विच चालू हो तो आवाज़ नहीं आती। फ़ाइल को “Files” ऐप से खोलना सबसे भरोसेमंद है; GitHub Pages पर प्रकाशित करने से बस URL खोलना काफ़ी होता है।

## संरचना

```
.
├── index.html            # app (HTML / CSS / JavaScript in one file)
├── sample/
│   └── participants.csv  # sample list
├── README.md             # + README.<lang>.md (16 languages)
└── LICENSE               # MIT
```

`index.html` में सब कुछ है: भाषा शब्दकोश, CSV पार्सर, सेटअप स्क्रीन, Web Audio से ध्वनि-निर्माण (ऑडियो फ़ाइलें नहीं), टाइमर लॉजिक (टाइमस्टैम्प-आधारित, इसलिए समय नहीं भटकता) और टाइमर स्क्रीन। सेटिंग्स और प्रगति `localStorage` में अपने-आप सहेजी जाती हैं।
