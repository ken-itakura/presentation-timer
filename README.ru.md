Одностраничный таймер, чтобы участники по очереди рассказывали о себе на встречах выпускников и подобных мероприятиях. Достаточно открыть `index.html` в браузере — без установки, сервера и интернета.

## Как пользоваться

1. Откройте `index.html` в браузере (Safari / Chrome).
2. На экране настроек: загрузите CSV (см. `sample/participants.csv` или «Загрузить пример»), отметьте присутствие каждого, отсортируйте по любому полю, задайте название / время на человека / обращение / язык и проверьте звуки.
3. Нажмите «К таймеру» (это также включает звук).
4. Ведите таймер:

| Действие | Результат |
|---|---|
| `Пробел` / кнопка «Старт» | Запустить следующего (с аплодисментами) |
| Клик по имени в правом списке | Запустить этого человека; стоявшие перед ним переходят в «Пропущенные» |
| Клик по имени в «Пропущенные» | Запустить этого человека |
| Снять отметку «Присутств.» в «Пропущенные» | После подтверждения отметить отсутствующим и убрать из списка (таймер не останавливается) |

За 10 с до конца: тик каждую секунду · за 3 с: частые гудки · на 0: звук взрыва и ярлык «Время вышло!». Справа вверху — общее прошедшее время, в правой колонке — следующие 10 человек.

## Формат CSV

Первая строка — заголовок. UTF-8 и Shift_JIS определяются автоматически. Столбцы имени и обращения выбираются по заголовку (например, `имя`, `обращение`) и меняются в настройках. Если ячейка обращения пуста, используется обращение по умолчанию.

```csv
name,honorific,group,year
Alex Morgan,,A,2001
Sam Rivera,Dr.,B,2001
```

## Языки

16 языков: переключайте через «Язык» на экране настроек (сначала берётся язык браузера, ваш выбор сохраняется). Тексты интерфейса, название и обращение по умолчанию, пример данных и положение обращения (перед/после имени) зависят от языка; для арабского используется раскладка справа налево. Переводы не проверялись носителями языка — исправляйте `I18N` в `index.html`. Чтобы добавить язык, добавьте записи в `LANGS`, `I18N` и `SAMPLE_NAMES`.

## Телефон

Раскладки для телефона в портретной и альбомной ориентации. На iPhone переключатель беззвучного режима отключает звук. Надёжнее всего открывать файл через приложение «Файлы»; при публикации на GitHub Pages достаточно открыть URL.

## Структура

```
.
├── index.html            # app (HTML / CSS / JavaScript in one file)
├── sample/
│   └── participants.csv  # sample list
├── README.md             # + README.<lang>.md (16 languages)
```

Всё находится в `index.html`: словарь языков, разбор CSV, экран настроек, синтез звуков через Web Audio (без аудиофайлов), логика таймера (на основе временных меток, без дрейфа) и экран выступлений. Настройки и ход выступлений автоматически сохраняются в `localStorage`.
